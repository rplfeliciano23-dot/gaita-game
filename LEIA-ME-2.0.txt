GAITA GAME 2.0 - PACOTE CONSOLIDADO

Este pacote reúne a versão mais recente do aplicativo e os arquivos de suporte necessários para executá-lo como PWA.

CONTEÚDO INCLUÍDO
- index.html: interface mais recente, tema natural, mascote, navegação com histórico, aulas, músicas, importação/exclusão, favoritos, recentes, backup/restauração, afinador com mapa/calibração e central de ajuda.
- gaita-architecture.js: fundação de dados pedagógicos e migração não destrutiva do progresso.
- sw.js: cache PWA atualizado para v12-natureza.
- manifest.webmanifest, ícones, textura-tronco.svg, fundo-natureza.webp e mascote-bem-te-vi.png.
- supabase-schema.sql e cloud-config.example.js: preparação opcional para nuvem.
- documentação técnica e plano de implementação.

INSTALAÇÃO
1. Faça backup de todos os arquivos atuais do projeto.
2. Extraia este ZIP.
3. Substitua os arquivos correspondentes na raiz do projeto hospedado. Não coloque os arquivos dentro de uma subpasta se o projeto atual publica a partir da raiz.
4. Mantenha todos os arquivos deste pacote juntos, na mesma raiz.
5. Publique no mesmo endereço HTTPS usado pelo PWA.
6. Feche e reabra o app. Se o Android mantiver uma versão antiga, atualize a página e aguarde o service worker v12-natureza assumir o controle.

DADOS
- O progresso continua salvo localmente no aparelho. Use o recurso de backup antes de trocar de aparelho ou limpar os dados do navegador.
- A nuvem ainda NÃO está ativa. Para ativá-la, é necessário criar um projeto Supabase, executar supabase-schema.sql, copiar cloud-config.example.js para cloud-config.js e inserir URL e chave pública do projeto. Nunca coloque service_role no frontend. O fluxo de autenticação/sincronização precisa ser integrado e testado antes de prometer sincronização entre aparelhos.

ÁUDIO REAL DE GAITA
- A demonstração musical ainda usa síntese Web Audio, não gravações reais de palhetas. O pacote não inclui samples reais licenciados por nota, sopro/aspiração e técnica. Não seria correto chamar o som atual de gravação real. Para chegar ao timbre autêntico, é preciso incorporar uma biblioteca de samples gravados/licenciados e mapear as notas.

LIMITES IMPORTANTES
- O afinador e a calibração usam microfone e precisam ser testados em aparelhos reais, com diferentes gaitas e ruído ambiente.
- A avaliação automática de execução não deve ser tratada como professor infalível: a detecção de frequência já existente é uma base, mas avaliação avançada de ritmo, bends, timbre e técnica exige calibração e testes acústicos.
- Comunidade, rankings online, painel administrativo e sincronização real dependem de backend, regras de privacidade, moderação e credenciais/serviços externos. Não estão ativos só por estarem documentados.

PLANO DE FUNDO NATURAL
- A interface principal agora usa fundo ilustrado de bosque iluminado, com folhagens, trilha e luz suave.
- Cartões recebem uma camada clara/translúcida para preservar a leitura; menus superiores e inferiores usam tons de verde-floresta.
- O arquivo fundo-natureza.webp precisa permanecer na mesma pasta do index.html. Ele também foi incluído no cache do PWA.
- Em aparelhos com modo escuro, a imagem recebe uma camada escura para manter o contraste.
